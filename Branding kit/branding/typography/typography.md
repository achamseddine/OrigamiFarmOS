# Typography

## Recommended fonts

- Display/headings: Fraunces, Georgia, or a refined serif fallback.
- UI/body: Inter, system-ui, Segoe UI, Arial.
- Arabic/RTL: Noto Sans Arabic, Tahoma, Arial.

## Usage

- Use display serif only for major headings such as `Good Morning, Rami`, `Animal Status`, and `Health Intelligence`.
- Use UI sans-serif for data-heavy cards, labels, tables, and forms.
- Avoid tiny text on tablet screens; 12 px should be the minimum for labels and 14–16 px for core text.
