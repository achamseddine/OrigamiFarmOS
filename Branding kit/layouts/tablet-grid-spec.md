# Tablet Grid Specification

## Canvas
- Target canvas: landscape tablet.
- Design reference: 4:3 presentation ratio, with realistic device frame.
- Implementation target: responsive landscape tablet from 1024 px to 1366 px width.

## Layout
- Left navigation: 200–240 px.
- Main content: fluid.
- Outer content padding: 32–40 px.
- Card gap: 16–20 px.
- Card radius: 20–28 px.
- Modal/panel radius: 28–36 px.

## Accessibility
- Touch targets: 48 px minimum.
- Text contrast: dark cedar/ink over stone background.
- Status should not rely on color alone; always include icon or label.
- Arabic RTL support is required.
